## 1. Project Overview

This project involves the design and development of a responsive website for the Animal Anti-Cruelty League (AACL).

The purpose of the website is to provide visitors with clear and accessible information about the organisation, its services and how members of the public can support animal welfare.

The website has been designed with a simple, professional and user-friendly interface. It provides information about animal welfare services, adoption, shelter, veterinary care, animal cruelty investigations and community outreach.



## 2. Organisation

The organisation selected for this project is the Animal Anti-Cruelty League (AACL).

The Animal Anti-Cruelty League is an animal welfare organisation in South Africa that works to protect animals from cruelty, neglect and abuse.

AACL has been protecting and caring for animals since 1956.

The organisation provides services including:

- Animal shelter
- Animal adoption
- Veterinary care
- Animal cruelty investigations
- Community outreach
- Animal welfare education



## 3. Website Goals

The main goals of the website are to:

1. Provide visitors with information about AACL.
2. Explain the services provided by the organisation.
3. Make it easier for people to contact the organisation.
4. Encourage responsible animal adoption.
5. Encourage volunteering and support for animal welfare.
6. Provide an online enquiry form.
7. Provide contact information for different AACL locations.
8. Create a professional and accessible online presence.



## 4. Target Audience

The website is designed for:

- Pet owners
- People interested in adopting animals
- Potential volunteers
- Donors and sponsors
- Animal welfare supporters
- People reporting animal cruelty
- Community members
- Schools and community organisations



## 5. Website Pages

The website contains five main HTML pages.

### Home

**File:** index.html

The homepage introduces visitors to the Animal Anti-Cruelty League and provides links to the organisation's main services.

### About Us

**File:** about.html

This page provides information about the organisation's history, mission, vision and target audience.

### Services

**File:** services.html

This page describes the different services provided by AACL, including animal shelter, adoption, veterinary services, cruelty investigations, community outreach and education.

### Enquiry

**File:** enquiry.html

This page contains an enquiry form that allows visitors to provide their name, email address, contact number, enquiry type and message.

### Contact

**File:** contact.html

This page provides contact information for different AACL locations and allows visitors to find the appropriate branch.
